Space Guard

Analiza el espacio del disco y detecta dónde se está yendo tu almacenamiento.

Aplicación de escritorio para Windows pensada para inspeccionar unidades, localizar carpetas pesadas y dar recomendaciones prácticas para liberar espacio sin borrar a ciegas.

Python Tkinter Windows 10/11
Espacio total 1 TB
Carpetas analizadas 8
Salida Informe + recomendaciones

Qué hace

Visión clara del estado del disco

  • Espacio total, usado y libre de cualquier unidad.
  • Carpetas del usuario que más ocupan.
  • Accesos rápidos a limpieza y almacenamiento.
  • Soporta carpetas sin permisos sin romper el análisis.

Valor técnico

Una app útil y muy “real”

  • Interfaz de escritorio clara y directa.
  • Escaneo recursivo de directorios con manejo de errores.
  • Buenas recomendaciones para uso personal o soporte técnico.
  • Ideal para enseñar automatización y producto práctico.

Cómo se presenta

Enfoque portfolio

Este proyecto encaja muy bien como ejemplo de aplicación de escritorio orientada a resolver un problema cotidiano. En el portfolio funciona como una pieza distinta al resto: más de producto, menos de dashboard.
