# Portfolio para GitHub Pages

Este proyecto es una web estática lista para publicar en GitHub Pages.

## Qué incluye

- Hero principal con CTA.
- Sección de proyectos destacados.
- Bloque "Sobre mí".
- Lista de habilidades.
- Zona de contacto.
- Diseño responsive y sin dependencias de backend.

## Cómo personalizarlo

1. Abre `index.html`.
2. Cambia `Tu nombre`, el correo y los enlaces de GitHub/LinkedIn.
3. Edita los proyectos y habilidades en `app.js`.
4. Ajusta colores, textos o secciones en `styles.css`.

## Cómo publicarlo en GitHub Pages

1. Sube esta carpeta a un repositorio en GitHub.
2. Ve a `Settings`.
3. En `Pages`, elige la rama `main` y la carpeta `/root`.
4. Guarda y espera unos minutos.

## Alternativas

- **Netlify**: arrastras la carpeta y publica muy rápido.
- **Vercel**: también sirve para sitios estáticos.
- **GitHub Pages**: ideal si quieres algo simple y gratis.

## Siguiente mejora recomendada

Si quieres, puedo convertir esta base en una versión más personal con:

- Foto tuya o avatar.
- Proyectos reales con capturas.
- Botones para descargar CV.
- Formulario de contacto.
- Sección de experiencia o estudios.
